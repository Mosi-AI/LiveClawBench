# Shop API Documentation

E-commerce mock service (`mock-shop`). Serves HTML pages for browser agents and JSON API routes for programmatic access.

> **Auto-generated OpenAPI spec:** `dist/openapi/shop.json` (produced by `bun run scripts/generate-openapi.ts`).
> The generated spec is the canonical reference for all JSON API routes.

> **Note:** `GET /health` is inherited from `mock-lib` and returns `{ ok: true, status: "healthy", service: "shop-mosi-backend" }`.

For implementation details (data types), see `docs/shop-internal.md`.
