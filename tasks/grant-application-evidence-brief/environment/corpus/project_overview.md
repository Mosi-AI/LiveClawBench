# Project Overview: Cross-Lingual Document Understanding (CLDU)

## Principal Investigator
Dr. Sarah Chen, Natural Language Processing Lab, Westbrook University

## Project Summary
The Cross-Lingual Document Understanding (CLDU) project develops transformer-based models
capable of extracting structured information from documents across 24 languages without
language-specific fine-tuning. The core innovation is a document-structure-aware attention
mechanism that jointly models layout, typography, and linguistic content.

## Research Goals
1. Achieve state-of-the-art cross-lingual information extraction on standard benchmarks
2. Reduce labelled data requirements by 60% through multilingual transfer learning
3. Support low-resource languages currently underserved by commercial NLP systems
