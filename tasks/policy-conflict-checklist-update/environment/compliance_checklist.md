# Compliance Checklist — Operational Reference
Last Updated: 2024-Q3 Review

## Data Management
- [ ] Data retention for customer PII: maximum 90 days post-transaction
- [ ] Annual data classification review completed
- [ ] Restricted data storage inventory updated quarterly

## Access Control
- [ ] Password rotation enforced: all accounts updated every 180 days
- [ ] Inactive accounts deprovisioned within 30 days of inactivity
- [ ] Two-factor authentication: strongly recommended for all admin accounts
- [ ] Privileged access review completed semi-annually

## Incident Response
- [ ] Security incident reporting procedure reviewed
- [ ] On-call rotation roster current
- [ ] Incident response runbooks updated quarterly

## Vendor Management
- [ ] Third-party vendor assessments completed annually
- [ ] Data processing agreements in place for all Tier 1 vendors
