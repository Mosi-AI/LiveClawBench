# Data Governance Policy v2.0
Date: March 1, 2023
Status: SUPERSEDED by v3.0 (April 2026) — FOR REFERENCE ONLY

## 1. Data Retention
Customer PII must be retained for a maximum of **90 days** after the last transaction.

## 2. Access Control

### 2.1 Password Rotation
All user accounts must rotate passwords every **180 days**.

### 2.2 Two-Factor Authentication
Two-factor authentication (2FA) is **strongly recommended** for all admin accounts.
Departments may enforce it as mandatory at their discretion.

## 3. Incident Response
- Security incidents must be reported within **48 hours** of detection.
- A post-incident review must be completed within 14 business days.

## 4. Vendor Management
Third-party vendor security assessments must be completed annually for all Tier 1 vendors.
