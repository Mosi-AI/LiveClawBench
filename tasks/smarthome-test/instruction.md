You are helping the user complete their morning home automation routine. The user has a smart home control panel available at http://localhost:5003.

- **Dashboard**: Overview of room conditions and thermostat status
- **Thermostat Control**: Adjust temperature and mode (comfort/eco/off)
- **Inventory Management**: View and manage items in fridge and pantry
- **Grocery Catalog**: Browse available products for ordering
- **Calendar**: View and update scheduled events including workout types

7. **Order groceries if needed** - If any essential items are low or missing, place a grocery order
