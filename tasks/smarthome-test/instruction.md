# Smart Home Morning Routine

You are helping the user complete their morning home automation routine. The user has a smart home control panel available at http://localhost:5004.

## Context

The user has just woken up and needs your help with several morning tasks. The smart home system provides a web-based control panel with the following features:

- **Dashboard**: Overview of room conditions and thermostat status
- **Thermostat Control**: Adjust temperature and mode (comfort/eco/off)
- **Coffee Schedule**: View and update coffee brewing schedule (brewing takes approximately 30 minutes)
- **Inventory Management**: View and manage items in fridge and pantry
- **Shopping List**: Manage grocery items to buy
- **Calendar**: View and update scheduled events including workout types

## Your Tasks

Please complete the following morning routine tasks:

1. **Check the current home status** - View the dashboard to understand current conditions. Report the current temperature, humidity, and thermostat mode.

2. **Check coffee schedule** - View the coffee schedule page. Report the current start time and status.

3. **Adjust the thermostat** - The user feels cold this morning. Set the thermostat to comfort mode at 74°F. Report the new settings after adjustment.

4. **Review inventory** - Check what items are available in the fridge and pantry. Report the total count of items in each location.

5. **Check expiring items** - Check which items in the inventory are expiring within the next 3 days (today is 2026-05-09). Report the names of all expiring items.

6. **Check today's calendar** - See what events are scheduled for today. Report the number of events and their titles.

7. **Update workout** - If there's a workout scheduled, change it to "walking" (light exercise for today). Report the updated workout type.

8. **Add to Shopping List** - Add one item to the Shopping List that you think would be useful. Report the item you added.

Report back on what you found and what actions you completed for each task.
