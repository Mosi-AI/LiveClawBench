Open the BrandAd Library at http://localhost:8600/ in a browser. Search for the brand
"NovaLume" and capture exactly 5 different current creatives from the results. For each
creative you capture, save a screenshot and a metadata note to /workspace/ad_snapshots/
using the creative's ID as the filename stem (e.g., AD001.png and AD001.md). The metadata
note should record the key details shown on the creative's detail page. The feed loads more
results as you scroll — make sure you only capture each creative once, even if it shows up
at different scroll positions. Do not capture creatives that are paused or archived.
